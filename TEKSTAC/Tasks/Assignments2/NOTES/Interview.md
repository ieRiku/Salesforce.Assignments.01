### Project Description



##### JIRA



In the first sprint, our team collaborated to design and execute manual test cases using Jira with the Zephyr plugin. We divided the workload, and I was responsible for creating and executing a subset of test cases. The results were captured in Jira, and later exported into structured files such as CSV and detailed PDF reports, which documented test coverage and execution status.



##### AUTOMATION TESTING



In the second sprint, I implemented automation for the same set of test cases. I built the framework inside the Salesforce.Automation.Testing2 project using Selenium WebDriver with TestNG. I structured the framework using the Page Object Model with FindBy annotations for maintainability, and I grouped test cases logically with TestNG groups while assigning execution priorities. To make the suite more flexible, I parameterized browser creation, which allowed cross-browser testing on different environments.



For reliability, I used explicit waits to handle dynamic web elements, and for reporting, I integrated Extent Reports, which generated colorful, user-friendly reports. I also maintained Git for version control and documented the automation process clearly. The extent report screenshot, project files, and case study documents included in my submission are proof of the framework and results.
